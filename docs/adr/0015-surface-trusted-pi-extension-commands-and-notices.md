# Surface trusted Pi extension commands and notices

Trusted Pi extensions register slash commands (e.g. `pi.registerCommand("fast", ...)` for `/fast on|off|status`) and emit fire-and-forget feedback via `ctx.ui.notify(...)`. ADR 0014 established the trusted-extension selection and that compatible confirm/select/input dialogs round-trip through T3 Code's user-request UX, but it left two gaps: users had no way to discover which slash commands a trusted extension registered, and `notify` output was silently dropped, so running `/fast on` executed but produced no visible confirmation.

This decision closes both gaps using surfaces that already exist. Pi's RPC `get_commands` response carries skills, prompt templates, and extension commands together; T3 Code previously parsed only `source: "skill"` entries and discarded the rest at the `PiSessionRuntime` seam. That seam now returns both skills and `source: "extension"` commands from the same response, and the no-session catalog probe maps the extension commands into the provider snapshot as slash commands. They appear in the composer's `/` menu exactly like Claude's commands. Selecting one inserts the command text; submitting sends it through the normal prompt path, which Pi executes as an extension command. Because `get_commands` only reports what the configured binary actually loaded, and T3 Code only loads the trusted-extension selection (ADR 0014), the menu is inherently scoped to trusted commands — no ambient commands leak in.

For feedback, a `notify` `extension_ui_request` now publishes a neutral `extension.notice` runtime event carrying the message and optional notify type. It renders as an informational timeline row, deliberately not a `runtime.warning`: "Fast mode: ON" is not a recoverable failure. The event is fire-and-forget — Pi does not await a response for `notify`.

Two behaviors are accepted and documented rather than changed. An unrecognized slash command (a typo, or a command whose extension is not trusted) is not intercepted: it passes through to the model as ordinary prompt text, matching how the composer already treats any non-built-in slash input. And only extension commands are surfaced in the menu — Pi prompt templates (`source: "prompt"`) are excluded from this surface, since they load under different trust rules than the trusted-extension selection.
